# SPLADE Benchmark on Azure NC24ads_A100_v4 / Standard_D32s_v6

Custom benchmarking toolkit for `bizreach-inc/light-splade-japanese` models on Azure NC A100 (GPU) and Standard_D32s_v6 (CPU). Measures latency (P50/P95/P99), throughput (QPS), sparsity, and GPU metrics across batch sizes and sequence lengths.

## Prerequisites
- Azure NC24ads_A100_v4 (GPU) or Standard_D32s_v6 (CPU)
- Ubuntu 22.04 or 24.04
- Sudo access for driver/CUDA install (GPU only)
- Internet access to download models/datasets

## 1) VM Bootstrap (run as root)

### GPU VM (A100)
```bash
sudo ./setup_azure_vm.sh --device cuda
sudo reboot
```

### CPU VM (e.g., Standard_D32s_v6)
```bash
sudo ./setup_azure_vm.sh --device cpu
```

## 2) Python Environment
```bash
sudo apt-get update && sudo apt-get install -y python3-venv python3.12-venv  # if ensurepip/venv is missing
./setup_python_env.sh --device cuda  # creates ~/splade_benchmark_env
source ~/splade_benchmark_env/bin/activate
```

### CPU-only environment
```bash
./setup_python_env.sh --device cpu
```

## 3) Prepare Data, Run Benchmark, Visualize

### Default (full profile, 14M model)
```bash
./run_full_benchmark.sh
```

This runs the **full** profile:
- Batch sizes: 1, 8, 32, 64, 128, 256
- Sequence lengths: 128, 256, 512, 1024
- Warmup: 10 iterations
- Measure: 100 iterations
- Padding: longest (dynamic)

### Online search profile (short + long queries)
```bash
PROFILE=online DEVICE=cuda VM_SKU=NC24ads_A100_v4 ./run_full_benchmark.sh
```

Profile details:
- **Short-query grid**: seq={16,32,64,128}, bs={1,2,4,8,16}
  - Warmup: 30, Iterations: 500
- **Long-query grid**: seq={256,512,1024}, bs={1,2,4}
  - Warmup: 50, Iterations: 500
  - Representative point: seq=512, bs=1
- Padding: max_length (fixed)

### CPU benchmark example
```bash
PROFILE=online DEVICE=cpu VM_SKU=Standard_D32s_v6 ./run_full_benchmark.sh
```

### Specify different model
```bash
# 28M model
MODEL="bizreach-inc/light-splade-japanese-28M" ./run_full_benchmark.sh

# 56M model
MODEL="bizreach-inc/light-splade-japanese-56M" ./run_full_benchmark.sh

# Or use Python directly
python benchmark_splade.py --model bizreach-inc/light-splade-japanese-28M --device cuda --vm-sku NC24ads_A100_v4
```

### Benchmark multiple models
```bash
for model in "bizreach-inc/light-splade-japanese-14M" \
             "bizreach-inc/light-splade-japanese-28M" \
             "bizreach-inc/light-splade-japanese-56M"; do
  MODEL="${model}" PROFILE=full ./run_full_benchmark.sh
done
```

## Advanced Options

### CPU thread tuning
```bash
python benchmark_splade.py \
  --model bizreach-inc/light-splade-japanese-14M \
  --device cpu \
  --cpu-threads 16 \
  --interop-threads 1 \
  --vm-sku Standard_D32s_v6
```

### Padding policy
- `--padding-policy longest` (default): Dynamic padding per batch
- `--padding-policy max_length`: Fixed padding to max_length

### GPU monitoring
- Enabled by default when running on CUDA
- Disable with `--gpu-monitor false`
- Adjust sampling interval with `--monitor-interval 0.5` (seconds)

## Key Features
- **OOM handling**: Auto-halves batch size on CUDA OOM
- **GPU monitoring**: Best-effort NVML-based metrics (auto-skipped if unavailable)
- **Per-sequence datasets**: Uses [`data/queries_{seq}.json`](data/) generated by [`scripts/prepare_data.py`](scripts/prepare_data.py)
- **Comprehensive metrics**: Percentiles (P50/P95/P99), throughput (QPS), sparsity, GPU utilization
- **Run metadata**: Device, VM SKU, batch size (requested vs actual), padding policy, thread settings

## Troubleshooting
- **OOM errors**: Batch size auto-halves on CUDA OOM. Manually reduce `--batch-sizes` if needed.
- **GPU not detected**: Verify `nvidia-smi` works and drivers are installed via [`setup_azure_vm.sh`](setup_azure_vm.sh).
- **NVML unavailable**: GPU monitoring gracefully degrades; benchmark continues without GPU metrics.
- **Slow downloads**: Set `HF_HOME` to a fast disk and optionally `HF_HUB_ENABLE_HF_TRANSFER=1`.
- **Missing datasets**: Run `python scripts/prepare_data.py --seq-lengths 128 256 512 1024` to generate test data.

## Environment Variables
- `DEVICE`: `cpu` or `cuda` (default: `cuda`)
- `PROFILE`: `full` or `online` (default: `full`)
- `MODEL`: HuggingFace model name (default: `bizreach-inc/light-splade-japanese-14M`)
- `VM_SKU`: Optional annotation for result metadata (e.g., `NC24ads_A100_v4`, `Standard_D32s_v6`)
- `ENV_DIR`: Python virtual environment path (default: `~/splade_benchmark_env`)
- `TOKENIZERS_PARALLELISM`: Set to `false` for stable GPU runs (auto-set by [`run_full_benchmark.sh`](run_full_benchmark.sh))
